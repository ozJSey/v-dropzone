Validation + click-to-pick

accept: 'image/*,.pdf', maxSize: 5 MB, clickToPick: true. Click anywhere in the box to open the native picker — except the inner button, which keeps its own click semantics.

Drop or click here

Upload progress (CSS variables)

Drop files to start a simulated upload. The directive writes --dropzone-progress (0–100) and --dropzone-files-pending on the host. The blue bar and the "N file(s) remaining" line below are pure CSS — no JS reads progress state. Files complete after 1.5s each; a randomly-chosen one fails so you can see the sticky error state.

Drop files here to upload

Paste-from-clipboard (anywhere on the page)

paste: true, pasteOn: 'document'. Press Cmd/Ctrl+V with an image in your clipboard (a screenshot, a copied web image, …) — the directive catches it and runs it through the same validation pipeline as drop / pick.

Programmatic API + queue (autoUpload: false)

The directive exposes a DropzoneApi via the ref option. Drop files (they queue — autoUpload: false), then use the buttons to open the picker, start the upload, cancel in-flight transfers, or retry failed ones.
